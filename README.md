# Live-Schema-Flow-Tracer-UX-Debugger
Live Schema Flow Tracer &amp; UX Debugger is a next-generation developer studio and real-time visual tracing extension for VS Code and modern AI IDEs. It provides live user journey mapping, bi-directional Mermaid &amp; ERD schema sync, video export with voiceover dubbing &amp; STT transcripts, multi-device viewport testing, and dynamic inline DAP breakpoints.
